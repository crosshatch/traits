name: http-api-servers
---

Model application HTTP endpoints and servers with Effect’s HttpApi and HttpApiBuilder. Declare paths, path parameters, payloads, responses and errors in HttpApi schemas, and use framework routing and request decoding rather than manual path switches, route regexes or ad-hoc JSON parsing. Retain custom middleware and wire codecs only for transport or protocol requirements not supplied by HttpApi.

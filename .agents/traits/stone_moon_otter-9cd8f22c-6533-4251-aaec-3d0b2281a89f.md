Write large text strings as multiline template literals using Effect’s `String.stripMargin`, with a leading `|` on each text line. Align each `|` and the closing backtick with the start of the containing statement or property, without an extra indentation level: ``instructions: String.stripMargin(`\n| text\n`)``, not ``instructions: String.stripMargin(`\n  | text\n`)`` (`\n` denotes a line break).
